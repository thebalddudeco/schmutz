How do I get the goods?

When products launch, each listing will link to its Etsy page for checkout and digital delivery. The current catalog contains design samples, so checkout is not available yet.

What software do I need?

Each product lists its intended application and file format. Check the product’s Etsy listing for the exact software version, included files, and any required fonts before purchasing.

Can I use these for client work?

Usage terms will be provided with each product’s Etsy listing. Review that product’s license before purchasing or using a template commercially.

Is this a custom design service?

Schmutz is a collection of editable resources. For custom photography, film, and creative projects, visit The Bald Dude Co. ↗.
