Gumroad order hash helper

Generate a hash entry from a buyer email and Gumroad order ID. Only the hash is added to the public purchase list.

Output

Copy into activeOrders

The raw email and order ID are used in this browser to calculate the hash. They are not saved by this page.

Add the generated object to activeOrders in plus-order-access-registry.js, then publish the updated files.

This is the same static purchase-list check used by GED Prep Hub. It does not query Gumroad or update itself when a subscription is canceled. Review renewals and remove access after cancellations, refunds, or disputes.
