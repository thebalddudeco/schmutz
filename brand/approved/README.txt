SCHMUTZ / APPROVED ASSET EXPORTS

Only the 16 SVGs from NEW ASSETS are used. Artwork, colors, letter spacing, trademark placement, and asterisk design are preserved. No fonts have been substituted and no artwork has been redrawn.

LOGOS
logos/original-canvas: untouched approved SVG masters, renamed descriptively.
logos/tight: the same path geometry with cropped outer canvas and clear space.
logos/webp: lossless transparent exports. Wordmarks: 320, 640, 1280, 2560 px wide. Monograms and asterisks: 64, 128, 256, 512, 1024 px wide. Heights follow the artwork proportions.

ICONS
Six color combinations, each with square and circular background styles. SVG masters and WebP sizes 64, 128, 256, 512, 1024. Transparent monogram and asterisk ICO variants are included as well.

FAVICONS
Six coordinated sets. Each contains an SVG master, lossless WebP sizes 16, 24, 32, 48, 64, 128, 180, 192, 256, 512, and one multi-resolution ICO with 16, 24, 32, 48, 64, 128, 256 px BMP frames. SVG and ICO are the browser favicon formats. WebP sizes are supplied as reusable site/app assets; installable app icon support varies by browser/platform.

Website favicons use favicons/asterisk-dark/favicon.svg and favicon.ico so the browser tab consistently shows the approved asterisk rather than the S monogram. The asterisk-dark version uses the orange symbol on an ink background. Retain the other light and dark variants for other uses.

FORMATS
SVG, WebP, ICO only for all artwork. No PNG or JPEG files, including preview images. Metadata and this guide are provided separately. Existing older files in A: have not been modified or deleted because this session cannot write there.

The overview displays every approved source. See manifest.json for exact source-to-output mappings, sizes, and source hashes. Original canvas spacing is retained in original-canvas; only outer whitespace changes in tight exports. Internal logo spacing and the trademark are never moved.

FRAME 18
The additional raster-only master is supplied as lossless WebP at 320, 640, 1280 and original width. No PNG copy, vector tracing, or upscaling is included.
